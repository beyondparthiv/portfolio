P-01 multiplayer · fintech sim

StockXchange

A real-time multiplayer stock-trading game inspired by the classic Indian board game. Players buy, sell, short and pass across trading rounds while procedurally generated news (some true, some false) moves the market.

Try it → trade the demo terminal. Keys B S X P, or click a ticker to switch charts.

  • Isolated the quant logic in a Python FastAPI microservice (NumPy/Pandas) for price settlement, P&L and event-card effects.
  • Next.js talks to the engine server-to-server, so the engine URL stays private and there's no CORS in the app path.
  • Lobbies and rooms sync live over Supabase Realtime; game state in Zustand.
